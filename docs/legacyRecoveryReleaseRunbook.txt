4. Πραγματική σύνδεση και CSRF
Χρησιμοποίησε το ήδη ανοικτό προφίλ περιηγητή που έχει πραγματική ενεργή είσοδο
στο http://localhost:5000. Δεν αντιγράφεις cookies, session IDs ή υπογραφές.

Τα cookies χωρίς domain/path '/', όπως ορίζονται στο config/sessionOpts.js,
μοιράζονται μεταξύ θυρών του ίδιου localhost. Δεν μοιράζονται με το 127.0.0.1.
Αν η πραγματική είσοδος έγινε στο 127.0.0.1, χρησιμοποίησε origin
http://127.0.0.1:5039 και άνοιξε ακριβώς αυτό, χωρίς μεταφορά cookies.
Host και Origin ελέγχονται ακριβώς. Η POST απαιτεί το ήδη υπάρχον
psifl.x-csrf-token cookie και ίδιο X-CSRF-Token header.
Ληγμένη συνεδρία, διαφορετικός Admin/εταιρεία ή λανθασμένο CSRF απορρίπτονται.
Η sessions διαβάζεται απευθείας: κανένα touch, set, upsert ή ανανέωση λήξης.

5. Προεπισκόπηση και διατήρηση αποτυπώματος
Η POST /recovery-preview καλεί την πραγματική previewLegacyFenceRecovery
με capability που εκδίδει η initializeIsolatedPreview για τον πραγματικό server.

δεν αποθηκεύει και δεν επιστρέφει approvalTicket. Σφραγίζει και επανελέγχει
ανεξάρτητα τα ιδιωτικά τεκμήρια, χωρίς εγγραφή στη βάση.

και της επανεκκίνησης μέχρι τη λήξη της υπάρχουσας συνεδρίας.

αυτόματα. Δεν εμφανίζονται αποτυπώματα ή μυστικά σε καταγραφές.

  set -euo pipefail
  dev_repo=/home/thanasis/Projects/Payroll-NodeJs
  test "$(git -C "$dev_repo" rev-parse --show-toplevel)" = "$dev_repo"
  test "$(git -C "$dev_repo" symbolic-ref --short HEAD)" = main
  test -z "$(git -C "$dev_repo" status --porcelain=v1 --untracked-files=all)"
  dev_before=$(git -C "$dev_repo" rev-parse HEAD)
  read -r -p 'Πλήρες SHA εγκεκριμένου merge με επιτυχές CI: ' expected_merge
  [[ "$expected_merge" =~ ^[0-9a-f]{40}$ ]]
  git -C "$dev_repo" fetch --no-tags origin main
  test "$(git -C "$dev_repo" rev-parse origin/main)" = "$expected_merge"
  test "$(git -C "$dev_repo" rev-parse "$expected_merge^{commit}")" = "$expected_merge"
  git -C "$dev_repo" merge-base --is-ancestor "$dev_before" "$expected_merge"
  test -z "$(git -C "$dev_repo" diff --name-only "$dev_before" "$expected_merge" -- .env '.env.*')"
  git -C "$dev_repo" diff --quiet "$dev_before" "$expected_merge" -- package.json package-lock.json
  test "$(git -C "$dev_repo" rev-parse HEAD)" = "$dev_before"
  test -z "$(git -C "$dev_repo" status --porcelain=v1 --untracked-files=all)"
  git -C "$dev_repo" merge --ff-only "$expected_merge"
  test "$(git -C "$dev_repo" rev-parse HEAD)" = "$expected_merge"
  test -z "$(git -C "$dev_repo" status --porcelain=v1 --untracked-files=all)"

Κάθε αποτυχία τερματίζει τη διαδικασία. Αν HEAD είναι ήδη expected_merge,
δεν υπάρχει νέα ενημέρωση και δεν προκαλείται χειροκίνητη επανεκκίνηση.
Διαφορετικό/νεότερο origin/main απαιτεί νέο χωριστά εγκεκριμένο στόχο με δικό
του επιτυχές CI. Απόκλιση ιστορικού: STOP, χωρίς merge commit/rebase/reset/stash.
Αλλαγή εξαρτήσεων: STOP, χωρίς npm install/npm ci στο ενεργό κύριο worktree.
Τα .env, αγνοημένα τοπικά αρχεία και πραγματικά δεδομένα δεν αντιγράφονται,
δεν διαγράφονται και δεν γίνονται μέρος του commit.
