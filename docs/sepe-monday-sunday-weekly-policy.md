# Πολιτική εβδομάδας Σ.ΕΠ.Ε. (2026-07)

Policy versions:

- weekly repo scenario: `repo-transfer-single-pair:v4`
- decision snapshot: `weekly-repo-transfer-decision-snapshot:v3`
- sixth/seventh day: `sepe-weekly-sixth-seventh-day:v1`
- work facts: `workFactsPrecalc:v2`
- carry-over: `weekly-payroll-carry-over:v1`

Η φυσική εβδομάδα ορίζεται αποκλειστικά ως Δευτέρα 00:00:00.000Z έως
Κυριακή 23:59:59.999Z. Η Κυριακή διατηρεί τη σημασία της για αργίες και
προσαυξήσεις, αλλά είναι η τελευταία ημέρα του εβδομαδιαίου bucket.

Τα αναμενόμενα ρεπό προκύπτουν αποκλειστικά από το ημερομηνιακά ισχύον
`hmeres_ergasias_ebdomadas`: `7 - hmeres_ergasias_ebdomadas`. Άρα πενθήμερο
σημαίνει `2` και εξαήμερο `1`. Δεν χρησιμοποιείται πρόσθετο ή παράλληλο
πεδίο ρεπό. Αλλαγή κρίσιμων όρων μέσα στην ίδια εβδομάδα
επιστρέφει `NEEDS_HR_DECISION / PROFILE_CHANGED_INSIDE_WEEK`.

Το ημερομηνιακά ισχύον `pososto_prosayxhshs_6hs_hmeras` αποθηκεύεται ως
ποσοστό (π.χ. `40`) στον εργαζόμενο και στο ιστορικό. Κενή, μη αριθμητική ή
αρνητική τιμή υφιστάμενου profile επιστρέφει
`MISSING_OR_INVALID_SIXTH_DAY_PREMIUM_RATE`; δεν εφαρμόζεται υπολογιστικό
fallback.

Οι εβδομάδες που διασχίζουν μήνα αξιολογούνται ολόκληρες. Οι εκτός
επιλεγμένου διαστήματος ημέρες είναι μόνο read context. Η μεταφορά ρεπό
επιτρέπεται μόνο όταν source και target βρίσκονται στον ίδιο μήνα και μέσα
στο επιλεγμένο διάστημα· δεν υπάρχει μεταφορά ρεπό σε επόμενη εβδομάδα ή
μήνα. Ανοικτή εβδομάδα δεν παράγει πρόταση πριν ολοκληρωθεί η Κυριακή.

Η source ημέρα είναι δηλωμένο ρεπό/μη εργασία με έγκυρα χτυπήματα και γίνεται
εργασία. Για πλήρη απασχόληση αναγνωρίζεται επίσης ως source μια πραγματικά
μη προδηλωμένη ημέρα: κενή κατηγορία, μηδενικές δηλωμένες ώρες, κανένα
δηλωμένο διάστημα και πλήρες έγκυρο ζεύγος κάρτας, εφόσον ο υπολογισμός την
έχει ήδη ταξινομήσει συμβατά ως εργασία. Η target ημέρα είναι προδηλωμένη
εργασία χωρίς κάρτα και γίνεται ρεπό. HR-declared άδεια, ασθένεια, αργία που
αποκλείει εργασία, κλειδωμένη ή χειροκίνητα ελεγμένη ημέρα απορρίπτεται
fail-closed. Μόνο προσωρινή άδεια που δημιούργησε αυτόματα ο ίδιος ο
υπολογισμός μπορεί να παραχωρήσει τη θέση της στο ρεπό.

Η ίδια μη προδηλωμένη source ημέρα ταξινομείται και στον ημερήσιο έλεγχο ως
`UNSCHEDULED_DAY_WITH_CARDS`, αντί για άγνωστο μοτίβο. Παραμένει πάντοτε
πρόταση προς ανθρώπινο έλεγχο, χωρίς auto-apply. Κενή ημέρα με ελλιπή κάρτα,
δηλωμένο διάστημα, ρεπό, άδεια, ασθένεια, αργία ή συγκρουόμενα απολογιστικά
στοιχεία απορρίπτεται fail-closed.

Η εφαρμογή είναι ατομική για τις δύο ημέρες. Μαζί με τα βασικά απολογιστικά
πεδία ενημερώνονται οι ώρες πραγματικής εργασίας, άδειας και αργίας. Το
`compensation_breakdown_apologistika` τίθεται σε `null` ώστε να
επανυπολογιστεί μετά τη μεταφορά και να μην παραμείνει παλιό ποσό.

Legacy decisions παραμένουν αναγνώσιμες. Reconstruction/apply με παλιό
proposal version αποτυγχάνει κλειστά ως μη υποστηριζόμενη έκδοση.
